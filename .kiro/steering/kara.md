# Kara

Browser-only KTV app built from songs the user owns: separation (htdemucs), synced lyrics, queue, mic scoring, recipe export/import, online rooms. All processing runs in the browser.

Specs: `docs/DESIGN.md`, `docs/spike-m1.md`.

House rules
- Legal line: upload only. No downloaders or URL import, no copyrighted media or lyrics in repo, site, relay or fixtures. Audio never leaves the device.
- No AI attribution in commits, PRs or files.
- Small PRs, one concern each. Work on a branch; never commit, push or merge.
- You have file read and write tools only, no shell. Claude Code runs builds and tests and sends back exact errors and paths.
- End every reply with the list of files you changed.
